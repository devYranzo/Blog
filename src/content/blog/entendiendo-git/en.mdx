# Understanding Git

Git is a version control system.

But before learning commands, it is worth understanding what problem Git is trying to solve.

## What problem does Git solve?

When we work on a project, our files are constantly changing.

Git allows us to keep and inspect the history of those changes.

For example:

```text
Project
   │
   ├── version 1
   ├── version 2
   ├── version 3
   └── current version
```
