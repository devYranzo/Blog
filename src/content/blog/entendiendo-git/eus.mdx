# Git ulertzen

Git bertsioak kontrolatzeko sistema bat da.

Baina komandoak ikasi aurretik, Git-ek zer arazo konpontzen duen ulertzea komeni da.

## Zer arazo konpontzen du Git-ek?

Proiektu batean lan egiten dugunean, gure fitxategiak etengabe aldatzen dira.

Git-ek aldaketa horien historia gordetzeko eta aztertzeko aukera ematen digu.

Adibidez:

```text
Proiektua
   │
   ├── 1. bertsioa
   ├── 2. bertsioa
   ├── 3. bertsioa
   └── uneko bertsioa
```
