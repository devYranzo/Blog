# Entendiendo Git

Git es un sistema de control de versiones.

Pero antes de aprender comandos, merece la pena entender qué problema intenta resolver.

## ¿Qué problema resuelve Git?

Cuando trabajamos en un proyecto, nuestros archivos cambian constantemente.

Git nos permite guardar y consultar la historia de esos cambios.

Por ejemplo:

```text
Proyecto
   │
   ├── versión 1
   ├── versión 2
   ├── versión 3
   └── versión actual
```
