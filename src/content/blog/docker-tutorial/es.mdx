# Entendiendo Docker

Docker es una plataforma para desarrollar, enviar y ejecutar aplicaciones en contenedores.

Pero antes de aprender comandos, merece la pena entender qué problema intenta resolver.

## ¿Qué problema resuelve Docker?

Cuando trabajamos en un proyecto, nuestros archivos cambian constantemente.

Docker nos permite crear entornos aislados y reproducibles para nuestras aplicaciones.
